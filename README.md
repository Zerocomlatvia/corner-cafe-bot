# Corner Café Bot — «Администратор»

Discord-бот для кафе. Команды:

- `/меню` — красивая карточка с напитками и ценами
- `/отзыв` — оценка от 1 до 5, текст и напиток; отзыв публикуется в канале отзывов
- `/настроить` — панель настроек (видите только вы): меню и цены, счётчик участников, каналы, сообщения от имени бота и доступ по ролям. Открывают администраторы (право «Управлять сервером») и выбранные роли

## Запуск (Windows)
1. Откройте файл `.env` и впишите токен бота после `DISCORD_TOKEN=` (без пробелов и кавычек). Сохраните (Ctrl+S).
2. Дважды щёлкните `start.bat`. При первом запуске он сам установит всё нужное.
3. В окне должны появиться строки «Бот запущен» и «Команды на сервере … : меню, отзыв, настроить».

Бот работает, пока окно открыто. Чтобы остановить его аккуратно (и отправить сообщение «ушёл на перерыв»), нажмите Ctrl+C в окне. Если просто закрыть окно крестиком, сообщение может не успеть отправиться.

## Запуск через терминал
```
npm install
node index.js
```
Нужен Node.js 18 или новее.

## Настройка
Почти всё настраивается в Discord командой `/настроить`:
- **Меню и цены** — добавить, изменить или удалить напиток (изменения хранятся в `data.json`, он создаётся сам; в `menu.js` лежит только меню по умолчанию и цвета).
- **Счётчик участников** — голосовой канал «Участники: N», обновляется раз в 10 минут. Боту нужно право «Управлять каналами» в этом канале.
- **Каналы** — меню-сообщение, отзывы, статус бота и патчи. Если канал не выбран в панели, берётся значение из `.env` (`MENU_CHANNEL_ID`, `REVIEWS_CHANNEL_ID`, `STATUS_CHANNEL_ID`, `PATCHES_CHANNEL_ID`). Отзывы публикуются только в канале отзывов; пока он не выбран, `/отзыв` ничего не отправляет.
- **Меню-сообщение** — бот публикует меню обычным сообщением в выбранный канал. Оно видно, даже когда бот выключен, и обновляется само при смене цен или оформления (при запущенном боте).
- **Оформление меню** — в разделе «Меню и цены» кнопка «🎨 Оформление»: заголовок, подзаголовок и подпись. В подписи можно писать `{отзыв}` и `{меню}` — это кликабельные ссылки на команды.
- **Написать от имени бота** — выбрать канал, написать текст (с заголовком получится карточка). Упоминания не пингуют.
- **Доступ** — какие роли, кроме администраторов, могут открывать `/настроить`. Этот раздел видят только администраторы.

## Статус и патчи
- В канале статуса остаётся только последнее сообщение («в сети» или «ушёл на перерыв»), старые бот удаляет сам.
- Патчи: откройте `changelog.js`, добавьте сверху новую запись с бóльшим номером версии и перезапустите бота — он сам опубликует её в канале патчей. Одну и ту же версию дважды бот не объявляет.

После правок кода остановите бота (Ctrl+C) и запустите заново.

Файл `.env` с токеном никогда не выкладывайте на GitHub и не показывайте на скриншотах.
